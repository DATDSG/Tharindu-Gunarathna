# Tharindu Gunarathna - Portfolio Website

Personal portfolio website showcasing AI & Quantum Computing research, projects, and academic profile.

## 🌟 Features

- **Responsive Design**: Fully responsive layout that works on all devices
- **Dark Mode**: Toggle between light and dark themes with persistent preference
- **Modern UI**: Clean, professional design with smooth animations
- **Accessible**: Built with accessibility best practices (WCAG compliant)
- **SEO Optimized**: Proper meta tags and semantic HTML structure
- **Fast Loading**: Optimized performance with minimal dependencies
- **Mobile-First**: Designed for mobile devices first, then scaled up

## 🚀 Quick Start

1. **Clone or download** this repository
2. **Open `index.html`** in your browser to view the site
3. **Customize** the content following the [Customization Guide](CUSTOMIZATION_GUIDE.md)

### Local Development

Simply open `index.html` in your browser, or use a local server:

```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000

# Node.js (if you have http-server installed)
npx http-server
```

Then visit `http://localhost:8000`

## ✏️ Customization

### Essential Updates

1. **Personal Information**: Update your name, title, and description in `index.html`
2. **Contact Details**: Add your email, LinkedIn, and GitHub links
3. **Content**: Replace placeholder content with your actual research, projects, and publications
4. **Colors**: Customize the color scheme in `styles/main.css` (CSS variables in `:root`)
5. **Images**: Add your profile picture and other images to the `assets/` folder

For detailed customization instructions, see [CUSTOMIZATION_GUIDE.md](CUSTOMIZATION_GUIDE.md).
